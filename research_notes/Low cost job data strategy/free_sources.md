# Free and freemium job-data sources

## Which sources are genuinely free, current, and usable in production?

### Takeaway
The strongest zero-marginal-cost production foundation is first-party employer ATS feeds plus a few explicitly reusable public APIs. “Free to test” is not the same as “free to warehouse or republish”: Adzuna, Remotive, Himalayas, The Muse, Careerjet, and Arbeitnow all impose link-back, usage-model, or commercial restrictions that OrbitHire must design around.

### Cited Findings
- **Tier 1 — first-party employer ATS feeds (highest quality/freshness, targeted coverage, $0 API cost):** Greenhouse states that published Job Board data is publicly available and needs no authentication for GET requests; the list response contains stable IDs, title, location, canonical application URL and `updated_at`, with full description available via `content=true`. This is employer-authoritative data, but one board token must be maintained per employer and the documentation does not grant a blanket copyright/republication licence. — [Greenhouse Job Board API](https://docs.greenhouse.io/job-board)
- **Tier 1 — Lever public postings (highest quality/freshness, targeted coverage, $0 API cost):** Lever distinguishes its publicly accessible Postings API for published jobs from its authenticated account API. This is another high-quality company-direct source, but also requires discovery and maintenance of company site IDs rather than offering cross-company search. — [Lever API support](https://hire.lever.co/developer/support)
- **Tier 1 — USAJOBS (authoritative, fresh, US federal only, $0):** OPM permits lawful commercial and noncommercial copying, storage, adaptation, publication, and redistribution of USAJOBS public data under an open licence. Search has no generally applicable request-count limit, but each query is capped at 10,000 rows and 500 rows per page; credentials are required and limits can change. OPM encourages source identification, a link to the official announcement, retrieval date, and an explicit non-affiliation statement. — [USAJOBS terms](https://developer.usajobs.gov/guides/terms-of-service); [USAJOBS rate limits](https://developer.usajobs.gov/guides/rate-limiting)
- **Tier 1/2 — Jobicy (good remote coverage, three-hour latency, $0 public or $0.01/direct link):** Its public API needs no key, exposes cursor pagination over jobs published in the past seven days, returns up to 200 jobs per page, and intentionally fixes a three-hour delay. Public results link to Jobicy and may be used in products with visible source credit. A commercial key replaces that URL with the direct ATS application URL where available at **$0.01 per newly returned job per API key**; repeats and jobs without a direct link cost $0. Job status checks are free in batches of 100. — [Jobicy API and RSS documentation](https://jobicy.com/jobs-rss-feed)
- **Tier 1/2 — Himalayas (good remote metadata, daily latency, $0):** The free API offers keyword, country, worldwide, seniority, employment-type, company and timezone filters, salary and expiry fields, and cursor pagination. With a free key, the published limit is 60 requests/minute and 10,000/day. The dataset refreshes every 24 hours, visible Himalayas attribution is required, applications must use the Himalayas link, and redistribution to other job boards/aggregators (including Google or LinkedIn Jobs) is prohibited. — [Himalayas API reference](https://himalayas.app/docs/remote-jobs-api)
- **Tier 2 — Remote OK (fresh remote niche, $0, link-back):** The live API currently includes a `last_updated` marker and jobs dated within the preceding few days, with title, company, tags, description, location, salary fields and Remote OK apply URL. Its embedded API terms require a followed backlink to the Remote OK job URL and source mention; a documented quota was not found, so production polling should be conservative. — [Remote OK live JSON API](https://remoteok.com/api)
- **Tier 2 — Arbeitnow (Europe/Germany plus separate UK feed, $0 but restrictive/unstable):** The official page says the no-key API aggregates recent jobs mostly from ATSs and supports `remote` and `visa_sponsorship=true|false` filtering; a UK endpoint launched in 2026. However, the current live Germany response exposes `slug`, company, title, description, `remote`, URL, tags, types, location and `created_at`, but **does not expose a `visa_sponsorship` boolean in returned job objects**, contrary to the pasted report. Its terms require a backlink and state access can be revoked at any time; the general site licence also says personal, noncommercial, transitory use, making commercial production use ambiguous without written permission. — [Arbeitnow API documentation](https://blog.arbeitnow.com/blog/job-board-api); [live Germany API](https://www.arbeitnow.com/api/job-board-api); [Arbeitnow terms](https://www.arbeitnow.com/terms)
- **Tier 2 — The Muse (curated company/jobs, generous technical quota, constrained reuse):** The public API returns JSON and allows 500 requests/hour anonymously or 3,600/hour with a registered app key. Its API licence permits displaying/distributing content as needed for an app, requires links back to The Muse, prohibits cloning Muse content or replicating Muse products, and forbids scraping. It is suitable as a linked search/display partner, not as an unrestricted warehouse. — [The Muse API](https://www.themuse.com/developers/api/v2); [The Muse API terms](https://www.themuse.com/developers/api/v2/terms)
- **Tier 2 — Reed (useful UK inventory, but production terms/quota need confirmation):** Reed’s public-facing site shows about 99,000 jobs and thousands added in 24 hours, while its historical Jobseeker API is documented as read-only search/detail with API-key Basic Auth. The current official developer endpoint is blocked to this research crawler and the recruiter policy’s 100 requests/user/day provision may apply to recruiter-site endpoints rather than the Jobseeker API. Therefore current price, redistribution rights, and exact quota remain **uncertain** and must be confirmed with Reed before launch. — [Reed jobs site](https://www.reed.co.uk/); [Reed recruiter policy](https://www.reed.co.uk/recruiter/policies); [Jentic summary of vendor OpenAPI](https://jentic.com/apis/reed.co.uk/reed)
- **Tier 3 — Adzuna (broad global aggregator, useful validation tier, not unrestricted free production):** Default access is only 25 hits/minute, 250/day, 1,000/week and 2,500/month—not the pasted report’s ~1,000–2,000/day. Publishing listings is an explicitly permissible use with strict Adzuna attribution, but other ongoing commercial/government/academic use is limited to a 14-day validation trial unless written consent/licensing is obtained. Access requires `app_id` and `app_key`. — [Adzuna API terms](https://developer.adzuna.com/docs/terms_of_service); [Adzuna overview](https://developer.adzuna.com/overview)
- **Tier 3 — Jooble (broad international aggregator, evaluation-only economics):** The 2026 official documentation states that the free REST plan is **500 requests total for the lifetime of each key**, not a recurring quota, and each national domain requires a separate key. The API is useful to benchmark recall in a few target markets, but cannot economically support periodic broad ingestion on the free plan. — [Jooble API documentation](https://help.jooble.org/en/support/solutions/articles/60001448238-rest-api-documentation); [Jooble API registration](https://jooble.org/api/about)
- **Tier 3 — Careerjet (broad global, user-triggered affiliate search rather than batch ingestion):** API v4 requires a publisher-site-specific key and requires the triggering user’s IP and user-agent on every query. It supports locale, keyword, location, contract/work-hours, date sorting, up to 100 results/page and up to 10 pages. Public documentation found no current price or quota, so cost is **unknown**; the request contract suggests interactive affiliate search, not unattended crawling/warehousing. — [Careerjet publisher API](https://www.careerjet.com/partners/api/)
- **Do not make a core source — Remotive public API:** Jobs are delayed 24 hours. Remotive requires both source credit and a link to the Remotive URL, forbids submitting its jobs to third-party sites such as Jooble, Google Jobs and LinkedIn Jobs, and expressly says collecting signups/emails in order to reveal a listing breaches its terms. A private paid API exists, but public pricing is not posted. — [Remotive public API and terms](https://remotive.com/remote-jobs/api)
- **Do not make a core source — Glassdoor scraping:** Glassdoor’s terms describe the service as personal/noncommercial absent a separate commercial agreement and expressly prohibit automated agents that scrape, strip, or mine data without written permission. It also prohibits using Glassdoor data in a competitive service. OrbitHire should use Glassdoor only as an outbound search/deep link or under a negotiated licence, not scrape it. — [Glassdoor Terms of Use](https://www.glassdoor.com/about/terms-2020-09-03/)
- **Do not treat JobSpy as a data licence:** JobSpy is an MIT-licensed implementation that scrapes LinkedIn, Indeed, Glassdoor and other boards and recommends proxies when boards block requests. The software licence covers the code, not rights to the scraped source content; its own documentation reports 429 blocking and roughly two requests/second Glassdoor throttling. Use it only for short-lived internal experiments on sources whose terms separately permit the activity, not as OrbitHire’s production supply. — [JobSpy README](https://github.com/speedyapply/JobSpy/blob/main/README.md); [GitHub repository metadata](https://github.com/speedyapply)

### Inferences
- **Recommended ranking for OrbitHire:** (1) approved company-direct ATS feeds, (2) USAJOBS for US federal, (3) Jobicy for low-cost remote/direct-link economics, (4) Himalayas and Remote OK as attributed remote discovery, (5) The Muse for curated breadth, (6) Arbeitnow only after commercial permission, (7) Reed after written confirmation, (8) Adzuna as a measured trial/licensed gap filler, (9) Jooble as a finite benchmark, and (10) Careerjet only for live user-triggered search. This ranking prioritizes employer authority, freshness, explicit production reuse, and marginal cost over raw volume. — [Greenhouse](https://docs.greenhouse.io/job-board); [USAJOBS](https://developer.usajobs.gov/guides/terms-of-service); [Jobicy](https://jobicy.com/jobs-rss-feed); [Himalayas](https://himalayas.app/docs/remote-jobs-api); [Adzuna](https://developer.adzuna.com/docs/terms_of_service)
- The pasted report’s “Adzuna free personal tier” framing is incomplete for a commercial OrbitHire product: the technical key is free, but ongoing commercial uses outside publishing attributed Adzuna listings may require consent/licensing after 14 days. — [Adzuna terms](https://developer.adzuna.com/docs/terms_of_service)
- The pasted report’s asserted Careerjet 50–100 calls/day, The Muse ~1,000/month, and Remote OK “updated hourly/unrestricted” figures were not supported by current official material. The Muse’s verified limits are much higher; Careerjet/Remote OK quotas remain unknown. — [The Muse API](https://www.themuse.com/developers/api/v2); [Careerjet API](https://www.careerjet.com/partners/api/); [Remote OK API](https://remoteok.com/api)

### Gaps
- Public pricing was not found for Remotive’s private API, Careerjet, Reed commercial use, Arbeitnow’s custom API, or Adzuna licences; mark all as “contact sales,” not $0, in financial planning. — [Remotive API](https://remotive.com/remote-jobs/api); [Arbeitnow API](https://blog.arbeitnow.com/blog/job-board-api); [Adzuna terms](https://developer.adzuna.com/docs/terms_of_service)
- No official, current production uptime/SLA was found for any no-key community feed. Treat these as opportunistic sources with health checks and circuit breakers rather than contractual inventory.

## What do government/public sources contribute?

### Takeaway
USAJOBS is the only source in this scope with both a clearly documented public job API and an unusually permissive downstream licence. Germany’s large Bundesagentur inventory is technically accessible through an undocumented endpoint, while EURES and MyCareersFuture are valuable portals but no stable public consumer vacancy API was verified.

### Cited Findings
- **USAJOBS:** Best legal certainty and directness, but narrow role/geographic coverage: US federal roles only, with eligibility/citizenship conditions that may sharply reduce relevance for OrbitHire’s broader audience. Public data may be reused commercially, but the official announcement remains authoritative. — [USAJOBS terms](https://developer.usajobs.gov/guides/terms-of-service)
- **Bundesagentur für Arbeit:** An open-source community wrapper documents the job-search endpoint, `X-API-Key: jobboerse-jobsuche`, search/detail flow, location/role/employer filters and `veroeffentlichtseit` recency filter. Crucially, that same project says the Bundesagentur still offers **no official API** for this job dataset. The official BA page documents an HR-BA-XML interface for employers to submit jobs, not a public job-consumer API. Production dependency on the undocumented read endpoint therefore has high change/terms risk despite excellent German coverage. — [bundesAPI community documentation](https://github.com/bundesAPI/jobsuche-api/blob/main/README.md); [official BA employer interface page](https://www.arbeitsagentur.de/unternehmen/arbeitskraefte/stellenangebot-melden)
- **EURES:** The official EURES portal exposes pan-European vacancies for interactive search, and EU materials show that national public employment services contribute vacancy data to EURES. This research found no official public, unauthenticated consumer API for downloading live vacancies; integration standards are oriented to EURES members/partners and national services. Use outbound links or pursue member/partner access instead of reverse-engineering portal calls. — [EURES portal](https://europa.eu/eures/portal/); [EU EURES implementation guidance](https://ec.europa.eu/info/funding-tenders/opportunities/docs/2021-2027/esf/guidance/implementing-guide_esf-2022-eures-tms_en.pdf)
- **MyCareersFuture:** GovTech describes it as Singapore’s government employment portal, with over 80,000 job postings, 50,000 employers and 280,000 jobseekers as of September 2026. No official public vacancy API or reuse terms were located. It is a high-value Singapore discovery/deep-link source, but not a validated ingestion source without a partner agreement. — [GovTech MyCareersFuture overview](https://www.tech.gov.sg/products-and-services/for-citizens/employment/mycareersfuture/); [MyCareersFuture portal](https://www.mycareersfuture.gov.sg/)

### Inferences
- Start USAJOBS immediately if federal jobs are strategically relevant. Put Bundesagentur behind an experimental feature flag and legal review, with no SLA assumption; do not promise coverage from EURES or MyCareersFuture until official access is granted. — [USAJOBS terms](https://developer.usajobs.gov/guides/terms-of-service); [bundesAPI warning](https://github.com/bundesAPI/jobsuche-api/blob/main/README.md)
- For EU breadth, national public APIs with explicit terms are safer than scraping EURES. EURES can remain a navigational source while OrbitHire investigates formal EURES membership/partner interfaces. — [EURES portal](https://europa.eu/eures/portal/)

### Gaps
- No public quota, licence, or official consumer documentation was found for the Bundesagentur’s internal job-search endpoint; technical accessibility is not permission.
- No verified live-vacancy consumer API was found for EURES or MyCareersFuture. Absence from search is not proof none exists; contact the operators before engineering against private endpoints.

## How should company websites, Workday, and other ATSs be used ethically and legally?

### Takeaway
Company-direct feeds are the best route to early, accurate jobs, but “publicly viewable” is not automatically “licensed for wholesale republication.” Prefer documented public ATS endpoints, retain employer canonical URLs, store only necessary facts, honour removals promptly, and obtain permission for Workday or bespoke sites whose terms/robots do not clearly allow automation.

### Cited Findings
- Greenhouse explicitly exposes employer-published jobs as public JSON without GET authentication and includes an `updated_at` field and canonical URL, making low-frequency change polling and deletion detection practical. — [Greenhouse Job Board API](https://docs.greenhouse.io/job-board)
- Lever explicitly calls its Postings API publicly accessible for a company’s published postings. — [Lever API support](https://hire.lever.co/developer/support)
- Workday documents that employer external career sites expose active job listings, posting dates, requisition numbers and job details, and can connect postings to third-party sites. This establishes that tenant career pages are intended for candidates, but the documentation found does **not** grant third parties a general cross-tenant aggregation licence. — [Workday Career Sites documentation](https://doc.workday.com/workday-education/en-us/course-manuals/recruiting-for-administrators/career-sites.html)
- Workday’s own end-user agreement prohibits automated access and scraping, but the cited agreement defines its covered “Website” as Scout RFP; it should not be overgeneralized automatically to every employer-owned Workday tenant. Each employer career site’s terms, robots directives and contractual authority still require separate review. — [Workday end-user agreement](https://www.workday.com/en-us/legal/end-user-agreement.html)
- Glassdoor’s terms expressly require written permission for scraping/mining and restrict commercial/competitive reuse. A first-party employer page or documented ATS endpoint is therefore the safer origin even when Glassdoor mirrors the same job. — [Glassdoor terms](https://www.glassdoor.com/about/terms-2020-09-03/)

### Inferences
- Maintain a curated **company registry** containing employer domain, career URL, ATS type, board/tenant identifier, permission basis, attribution rule, crawl interval and last successful fetch. Pull Greenhouse/Lever only through documented public GET endpoints; for Workday and custom sites, require either employer permission, a documented integration/feed, or an explicit legal review of site terms and robots before enabling automated ingestion. — [Greenhouse](https://docs.greenhouse.io/job-board); [Lever](https://hire.lever.co/developer/support); [Workday](https://doc.workday.com/workday-education/en-us/course-manuals/recruiting-for-administrators/career-sites.html)
- Store normalized metadata and a searchable excerpt where permitted, but make the primary action a canonical employer/partner application link. Recheck active jobs and remove closed/deleted posts within one polling cycle. This improves freshness and reduces stale-copy and copyright risk. — [Jobicy status API guidance](https://jobicy.com/jobs-rss-feed); [USAJOBS official-link guidance](https://developer.usajobs.gov/guides/terms-of-service)
- Do not bypass bot controls, rotate proxies to evade blocks, or imitate private browser APIs. JobSpy’s proxy/bypass advice may be technically effective but conflicts with the conservative legal posture required for a durable commercial product. — [JobSpy README](https://github.com/speedyapply/JobSpy/blob/main/README.md); [Glassdoor terms](https://www.glassdoor.com/about/terms-2020-09-03/)

### Gaps
- Greenhouse and Lever’s technical documentation confirms public access but does not by itself settle every employer’s copyright, database-right, or downstream-display terms. Obtain counsel and, for priority employers, written opt-in.
- A current official, public Workday vacancy API/licence for third-party aggregators was not found. Reverse-engineered Workday CXS endpoints should not be treated as approved merely because they return JSON.

## What minimal-cost portfolio and polling cadence should OrbitHire adopt?

### Takeaway
Use a two-speed portfolio: high-frequency delta polling for explicitly public first-party sources, slower attributed syncs for remote aggregators, and on-demand calls for quota-limited commercial aggregators. At launch, API spend can be near zero; optional Jobicy direct links create a transparent variable cost of roughly $10 per 1,000 newly returned jobs with direct ATS links.

### Cited Findings
- **Core $0 supply:** curated Greenhouse + Lever employers, USAJOBS, Jobicy public, Himalayas, Remote OK, and The Muse can all be accessed without per-request fees under their documented access models, subject to their distinct source-credit, link-back, app-registration, and non-republication restrictions. — [Greenhouse](https://docs.greenhouse.io/job-board); [Lever](https://hire.lever.co/developer/support); [USAJOBS](https://developer.usajobs.gov/guides/terms-of-service); [Jobicy](https://jobicy.com/jobs-rss-feed); [Himalayas](https://himalayas.app/docs/remote-jobs-api); [Remote OK](https://remoteok.com/api); [The Muse](https://www.themuse.com/developers/api/v2)
- **Optional direct-link spend:** Jobicy’s $0.01 charge applies only once per API key for a newly returned job that has a direct employer application URL, so the maximum listed-variable cost is $10 per 1,000 such unique jobs; repeated retrieval is free. — [Jobicy API](https://jobicy.com/jobs-rss-feed)
- **Quota-limited trials:** Adzuna’s default allowance is 250/day and commercial use may need a licence after 14 days; Jooble’s free key has only 500 lifetime requests. — [Adzuna terms](https://developer.adzuna.com/docs/terms_of_service); [Jooble docs](https://help.jooble.org/en/support/solutions/articles/60001448238-rest-api-documentation)
- **Source-native cadence signals:** Jobicy advises no more than one new sync per hour and says a few passes per day are generally enough; Himalayas refreshes every 24 hours; Remotive delays the public feed by 24 hours; Remote OK’s live response contains posts from the past few days but publishes no quota/cadence guarantee. — [Jobicy docs](https://jobicy.com/jobs-rss-feed); [Himalayas docs](https://himalayas.app/docs/remote-jobs-api); [Remotive API](https://remotive.com/remote-jobs/api); [Remote OK API](https://remoteok.com/api)

### Inferences
- **Phase 1 portfolio (near-zero cash cost):** poll 200–500 hand-picked employer ATS boards, USAJOBS, Jobicy public, Himalayas, Remote OK and The Muse; use outbound canonical links and render mandatory attribution per record/source. Exclude Glassdoor, Remotive, and raw Workday scraping from production. Keep Arbeitnow disabled until written commercial permission and Reed disabled until current terms/quota are confirmed. — [Arbeitnow terms](https://www.arbeitnow.com/terms); [Glassdoor terms](https://www.glassdoor.com/about/terms-2020-09-03/); [Remotive terms](https://remotive.com/remote-jobs/api)
- **Phase 2 paid only where metrics justify it:** turn on Jobicy’s direct-link mode first because the cost is explicit and granular; trial Adzuna for geographic gaps and negotiate only if it adds verified, unique applications; spend Jooble’s 500 calls solely on a controlled recall benchmark, not continuous ingestion. — [Jobicy](https://jobicy.com/jobs-rss-feed); [Adzuna](https://developer.adzuna.com/docs/terms_of_service); [Jooble](https://help.jooble.org/en/support/solutions/articles/60001448238-rest-api-documentation)
- **Recommended polling cadence:** Greenhouse/Lever priority employers every 15–30 minutes, long-tail employers every 2–6 hours; USAJOBS every 30–60 minutes using maximum page size and narrow changed windows; Jobicy every 1–3 hours; Remote OK every 2–4 hours; The Muse every 2–6 hours; Himalayas once daily after its refresh; Arbeitnow every 4–6 hours only if approved; Adzuna/Careerjet/Reed only on user search or scheduled gap-fill within written quotas; Jooble manually during benchmark periods. The sub-hour first-party cadence is an engineering judgment, while Jobicy/Himalayas limits derive from their published refresh guidance. — [Jobicy cadence](https://jobicy.com/jobs-rss-feed); [Himalayas refresh](https://himalayas.app/docs/remote-jobs-api); [USAJOBS limits](https://developer.usajobs.gov/guides/rate-limiting)
- **Freshness controls:** use stable source IDs plus canonical URL for deduplication; preserve source `published_at`/`updated_at` separately from OrbitHire `first_seen_at`/`last_seen_at`; status-check or refetch active posts; tombstone missing jobs only after repeated misses; retain per-source provenance and attribution text. These controls are necessary because source freshness ranges from near-live first-party data to explicit 3-hour and 24-hour delays. — [Greenhouse fields](https://docs.greenhouse.io/job-board); [Jobicy delay/status](https://jobicy.com/jobs-rss-feed); [Remotive delay](https://remotive.com/remote-jobs/api)
- **Quality score:** assign highest confidence to employer/official agency canonical postings, then partner feeds with direct employer URLs, then attributed aggregator-only URLs. Penalize jobs with no original publication time, missing company identity, stale status, duplicate descriptions, unclear employment type, or unverified sponsorship claims. The Arbeitnow discrepancy demonstrates that sponsorship should be stored as `explicit`, `text_inferred`, or `unknown`, never silently converted to a boolean. — [Arbeitnow documentation](https://blog.arbeitnow.com/blog/job-board-api); [Arbeitnow live API](https://www.arbeitnow.com/api/job-board-api)

### Gaps
- The optimal ATS polling interval depends on the final employer count, serverless/edge request cost, and observed change rate; run a two-week measurement before fixing production cadence.
- “Latest” cannot be guaranteed across aggregators that intentionally delay or batch-refresh data. OrbitHire should expose source publication time and data freshness rather than label all records “real time.” — [Jobicy](https://jobicy.com/jobs-rss-feed); [Himalayas](https://himalayas.app/docs/remote-jobs-api); [Remotive](https://remotive.com/remote-jobs/api)
